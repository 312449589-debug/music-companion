# 任务15：整段重新生成

## 实现范围

- 提交描述时带当前作品编号；服务端从完整原作品读取速度、调性，客户端不能指定替代约束。缺失或损坏原作品时拒绝，未调用AI。
- 在模型提示中明确保持原速度/调性，并再次检查真实输出。改变这些字段时最多一次模型修正；不会在服务端改写错误速度或调性冒充合格输出。只改标题或编号、音乐音符相同，也拒绝。
- 当前展示作品与待处理任务分开。处理中/失败时旧谱面和文件保留，标明“上次作品”；新结果全部ready并匹配来源/速度/调性后，统一切换整个作品对象和内容区域。
- 新请求、取消、继续查询均有响应轮次和任务编号检查，过期响应不能修改当前作品。
- 切换前停止旧内容区中的audio并归零；整个内容区随作品编号重新挂载。当前还没有正式播放器，实际播放中换曲验证在任务16接入播放器后执行，不声称本任务已实际试听。

## 本机操作验证

1. 双击“检查整段重新生成.command”，Chrome打开 http://127.0.0.1:8003/diagnostics/regeneration 。页面读取任务14验证的真实作品副本，不生成模板。首次运行依赖已有creation-page-check.json报告及真实文件。
2. 原作品应为“轻快两小节指弹”，100 BPM、C调，两个文件链接属于原任务。
3. 修改描述，点击“重新生成整段”，快速连续点击也只提交一个任务。处理中旧谱面和链接仍在，输入和提交按钮禁用。
4. 本诊断服务每次启动后的首次重新生成故意失败，不调用模型；应保留新描述、旧作品和可用旧文件，提供“重试重新生成”。正式服务没有此故障开关。
5. 点击重试，使用真实AI、音频和PDF导出。完成后标题、谱面、作品编号、音频与两个下载链接统一切换，速度/调性仍与原作一致。可用描述：“换成略带忧伤的两小节指弹旋律，希望72 BPM、D大调。旋律和低音和声同时演奏，不使用延音线。”原速度/调性约束优先。
6. 如AI候选被音乐规则拒绝，应继续保留旧作品，修改描述或点击重试。不要把失败当成功。

## 本轮修复

- 正式紧凑模型的duration_ticks限定为现有合法四分/八分/十六分等时值及附点时值，offset_tick在小节内且为可表示节奏网格。提前检查起点加时值不超过1920tick、旋律不重叠。
- 当前紧凑生成仅输出小节内音符，tie为none，避免模型写不成对的跨小节连音；不自动删除连音、移动音符或改写音高去凑通过。通用作品结构与历史作品的合法连音仍支持。
- 数据结构错误记录具体字段路径与错误类型；边界/重叠提供安全说明；不记录原始供应商响应、密钥或错误输入值。将这些信息传回第二次纠错并写入manifest，不再只返回通用结构错误。
- 生产指令说明可检查的经过/辅助音连接、导音在小节边界的起止关系。功能和声与可演奏性检查保持，最多两次候选，不增加无限重试或模板替代。

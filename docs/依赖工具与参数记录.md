# 任务02：依赖工具与参数记录

## 检查方式

可以直接双击根目录 `检查开发环境.command`。检查完毕会保留终端窗口，显示通过或具体缺失项。

项目根目录执行：

```bash
backend/.venv/bin/python backend/scripts/check_environment.py --sound-check --play
```

FluidSynth、FFmpeg、Chromium、中文字体、SoundFont 和音色诊断应显示“可用”。音色诊断播放六弦到一弦的开放弦；生成的 WAV 是环境检查素材，不是 AI 作品。Chromium 检查生成中文测试 PDF，位于 `runtime/diagnostics/font-check.pdf`。该检查不请求模型、不扣除模型预算，也不显示密钥。

运行失败时输出缺失项和修复办法，报告保存到 `runtime/diagnostics/environment-report.json`；该目录不提交 Git。模型信息可以显示“待接入时验证”，因为真实调用属于任务04。

## 安装来源和音色许可

- FluidSynth / FFmpeg 使用 conda-forge 分发，在项目 `.tools/audio` 内安装；不修改系统级目录。安装工具使用 [Micromamba 官方下载方法](https://mamba.readthedocs.io/en/latest/installation/micromamba-installation.html)。[FluidSynth 的 conda-forge 安装说明](https://github.com/conda-forge/fluidsynth-feedstock)。
- Chromium 使用 Playwright 1.58.0 官方安装器下载，浏览器缓存放项目 `.tools/browsers`。
- 音色：MuseScore 仓库提供的 `FluidR3Mono_GM.sf3`，General MIDI 的零起点 program 24 为尼龙弦吉他。来源：[音色文件](https://github.com/musescore/MuseScore/blob/main/share/sound/FluidR3Mono_GM.sf3)。许可与原始作者信息：[FluidR3Mono_License.md](https://github.com/musescore/MuseScore/blob/main/share/sound/FluidR3Mono_License.md)。许可副本与下载文件同存于 `.tools/soundfonts`；若分发音色需保留许可和归属信息。SF3 是压缩 SoundFont，FluidSynth 可用，并非 WAV 改后缀。
- 中文字体使用本机 Songti SC；不将系统字体复制到仓库，也不承诺该字体随应用分发。
- 实际检测版本见开发验收记录；安装环境的精确包清单保存为 `.tools/audio-explicit.txt`，不提交大体积工具和素材。安装器在 `~/.conda/environments.txt` 登记了本项目环境路径，不修改 shell 配置。

## 已确认参数

- 模型供应商为阿里云百炼千问，开发测试总预算不超过200元；具体型号、账号地域及凭证在测试接入时确定。

- 难度主要参考 BPM，仍检查指型和节奏可演奏性，不增加水平定位或等级界面。
- 最终 MP3 含尾音和编码影响在内，总时长不超过60秒。
- 整段重新生成保留当前作品 BPM 和调性，只改变音乐内容。

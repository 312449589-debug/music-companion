# 音乐伙伴 Music Companion

把你的音乐想法，变成可以亲手弹奏的小作品。

音乐伙伴面向吉他指弹学习者，教师也可以使用同一页面。用户通过文字描述喜欢的听感，生成一段简单的吉他指弹作品，随后查看六线谱、试听，并分别下载音频与乐谱。

## 当前进度

本仓库目前用于保存桌面网页的静态状态设计与演示说明，目标是在三天内完成本地 demo，优先适配电脑端 Chrome。

- 已完成：10 个主页面状态设计、5 组可复用组件及演示说明。
- 尚未实现：可运行的网页、输入与按钮交互、音频播放和实际下载。
- 演示中的作品、谱面、音频及下载反馈均为模拟内容，不代表实际 AI 生成结果。
- demo 阶段不要求接入真实 AI；后续计划使用阿里云百炼千问。

## 核心流程

输入或编辑提示词 → 生成作品 → 查看六线谱与试听 → 分别下载 MP3 / PDF，或修改提示词后重新生成整段。

示例提示词包括「温暖安静」「轻快明亮」「略带忧伤」。选择示例只填入可继续编辑的描述，不立即生成。

无需登录、注册或测评即可开始创作。

## 产品范围

- 仅支持吉他标准定弦：E A D G B E（六弦至一弦）。
- 作品形式为简单和声加旋律。
- 演奏时长不超过 1 分钟。
- 不支持打板类技巧。
- 合成音频需明确说明，不能冒充真人演奏。
- MP3 和 PDF 独立下载，不提供 ZIP 打包下载。

## 状态与交互规则

| 状态 | 行为 |
| --- | --- |
| 初始 | 展示输入区、示例提示词和生成按钮；结果区为空，不预置伪造作品 |
| 生成中 | 显示创作状态，防止重复提交，不显示虚假进度或预计完成时间 |
| 生成成功 | 同时展示六线谱、播放器与 MP3 / PDF 下载按钮 |
| 生成失败 | 保留用户输入，在创作区附近提示错误并提供重试；不以模板作品冒充成功 |
| 整段重新生成中 | 保留上一首完整结果，并明确标注为上一次作品 |
| 重新生成成功 | 同步更新谱面、音频和两个下载对象 |
| 重新生成失败 | 保留旧结果，允许重试生成 |
| 下载失败 | 允许重新下载当前作品，无需重新生成音乐 |

播放器仅包含播放、暂停和时间显示。

## 设计资料

- 演示与交互说明。

PNG 用于展示设计，不包含可点击交互；可编辑组件保留在 Figma 中。

## 待确认事项

音符密度作为主要难度指标，但具体阈值尚未确定。当前不设计难度等级、评分或水平测试。

## 暂不包含

账号、社区、云端作品库、哼唱录音、局部生成、音符编辑、速度或调性调节、循环播放、跟谱高亮、练习评分与进度、每日计划、教师管理、其他乐器及安卓页面。

# 任务16：真实MP3播放与暂停

## 改动

新增AudioPlayer组件，使用当前作品的最终MP3，不合成另一份试听音频。提供播放/暂停、当前位置、实际总时长、进度、加载/结束及失败提示；重试只重新加载音频，不重新作曲。初始没有作品时禁用。切换作品或离开页面时暂停旧媒体、释放旧来源；新作品默认从0开始。

React开发严格模式会执行一次额外的效果清理；组件在每次效果挂载时重新设置音频来源，避免清理后只剩一个不能播放的按钮。

## 亲自验证

1. 保持“检查整段重新生成.command”窗口打开，Chrome进入 http://127.0.0.1:8003/diagnostics/regeneration 。底部播放器标注“合成音频”，初始0:00。
2. 点击播放，应听见当前作品，按钮变为暂停，时间和进度向前。
3. 点击暂停，应停止播放并保留位置；再点播放从该位置继续，结束后按钮恢复播放，可再次从头播放。
4. 修改描述、重新生成。等待期间仍可试听旧作品；成功切换后旧声音停止、新进度为0、需手动点击播放新作品。不会自动播放新作品。
5. 开发失败诊断中让当前音频请求不可取得：显示“音频暂时无法播放…”，乐谱保留。恢复原文件，点“重试试听”即可播放，作品编号及模型调用次数不变。

# 任务04：千问接入与预算说明

状态：2026-10-10北京qwen-plus两条真实提示词、无效密钥和零预算诊断均通过，详见开发验收记录。此任务不包含生成网页接口、指型算法、谱面、音频或PDF导出。

## 本机配置

根目录 `.env` 是唯一人工填写密钥的位置，Git 已忽略。密钥不写入代码、请求日志、候选文件和提交。编辑器保存后诊断脚本会重新读取，无需将密钥发给 Codex。

- `DASHSCOPE_API_KEY`：实际百炼密钥。
- `QWEN_MODEL`：首轮测试用 `qwen-plus`，关闭思考模式。此选择验证音乐候选输出，不宣称已验证最好听的模型。
- `QWEN_BASE_URL`：以密钥对应服务地域及控制台调用示例为准，必须是官方 HTTPS 地址，不能把北京密钥用于国际接口。
- 本机已按用户确认的华北2（北京）配置为 `https://dashscope.aliyuncs.com/compatible-mode/v1`。
- `QWEN_INPUT_PRICE_PER_MILLION_CNY`、`QWEN_OUTPUT_PRICE_PER_MILLION_CNY`：实际地域/型号/非思考模式的输入与输出单价。
- `AI_BUDGET_CNY`：本项目测试总额，最大200元，可以降低；不能通过改配置提高上限。

截至2026-10-10，[qwen-plus官方模型页](https://help.aliyun.com/zh/model-studio/qwen-plus)列出北京地域、输入不超过128k的非思考模式原价为输入0.8元/百万token、输出2元/百万token。国际地域单价不同，不能沿用北京配置。计费以控制台实际账单为准，模型或价格变动时更新配置。

请求使用[百炼官方JSON Object模式](https://help.aliyun.com/zh/model-studio/qwen-structured-output)，将音乐Schema写入提示词，返回后用Pydantic严格检查结构。它保证JSON格式而不自动保证音乐数据正确，结构不合格会明确失败。JSON Schema模式的支持范围不同，当前不假设所有型号和地域都支持。

## 调用与候选数据

`app/providers/qwen.py` 独立封装供应商调用，`check_qwen.py` 提供命令入口。模型必须创作旋律、简单和声伴奏和创作说明；诊断生成2—4小节用于检验连接，不把这一长度作为产品生成默认值。候选包含 `creative_plan` 以及任务03的 `Composition`。

每次候选保存到 `runtime/ai/<本机请求编号>/candidate.json`，脱敏请求信息保存在 `request.json`，记录配置型号、响应型号、供应商请求编号、token用量、尝试次数和费用估算。凭证与原始HTTP错误响应不写日志；文件不提交Git。

候选通过只意味着模型调用和数据结构通过。时长、弦位音高、跨度、换把、音乐质量以及真实MP3/PDF仍需任务05及后续任务检查。没有静默模板回退。

## 预算与失败处理

- `runtime/ai/budget.json` 持久保存调用费用记录，锁文件保护同一电脑的并发预留；启动后不会自动清零。
- 每次调用前按请求字节长度和最大输出长度保守预留费用；余额不足时，在发送HTTP请求前拒绝。
- 成功取得供应商用量后按当前配置单价计算费用；不依赖免费额度或缓存优惠。
- 超时、网络失败或无法确认用量时，保留该次完整预留；重试也必须重新检查并预留预算。默认最多2次尝试；认证或结构错误不自动重试。
- 总预算覆盖本项目记录的调用，不包含你从控制台或其他软件发起的请求。本地金额是估算，不是阿里云账单；保留账本并核对实际账单，不删除账本来重置预算。当前模型诊断没有修改云端费用限制或账户设置。

## 用户验收

配置齐全后，双击项目根目录 `测试AI连接.command`，依次检查：

1. 零预算显示“预算检查已拒绝调用，未发送模型请求”。
2. 固定无效密钥显示“认证失败明确报错，没有模板结果”。该检查不会修改你保存在 `.env` 的真实密钥。
3. “温暖安静，适合夜晚弹奏”和“轻快明亮，简单和声加旋律”分别返回 `candidate_ready`、创作说明、请求编号与音乐候选路径。

也可在项目根目录执行：

```bash
backend/.venv/bin/python backend/scripts/check_qwen.py --status
backend/.venv/bin/python backend/scripts/check_qwen.py --budget-check
backend/.venv/bin/python backend/scripts/check_qwen.py --invalid-key-check
backend/.venv/bin/python backend/scripts/check_qwen.py
```

默认最后一条会发起两次真实创作，反复运行会累计费用。若失败，输出安全错误代码；返回成功候选前不会宣称任务完成。

离线测试使用 `httpx.MockTransport`，只验证预算和错误分支，不替代上述真实API验收。

# 任务05：音乐基础规则检查

入口：`backend/scripts/check_music.py`。检查固定诊断样例或已保存的真实AI候选，不请求AI、不修改文件、不自动修正音符。

## 检查什么

- 严格结构检查：局部速度/调性、打板技巧等不能藏在额外字段中。
- 标准定弦；每个音符的实际音高等于所属弦空弦音高加品位。
- 小节从0开始连续排列，长度符合全曲拍号；事件使用全曲绝对位置，位于所属小节内。
- 实际音符/休止长度与谱面时值一致，支持十六分音符及附点；跨小节延音拆成相邻、同声部同弦同音的连线事件，拒绝悬空连线。
- 小节和事件编号唯一；BPM有限且大于0，调性不是空白，作品至少有可发声音符。
- 所有声部共用一条时间轴，按结束位置计算演奏时长，不能把同时发声的旋律和伴奏串起来相加。保留完整小节及末尾休止时间；没有事件的位置按静默处理。

时长公式：`结束tick ÷ ppq × 60 ÷ BPM`。诊断样例两小节4/4，共8个四分音符；80 BPM为6秒，120 BPM为4秒。

本任务拒绝演奏超过60秒，**不将演奏恰好60秒视为最终音频合格**。音频合成会增加尾音和编码影响，任务09/11需预留空间并检查最终MP3，不截断未结束的音符。

本检查不替代任务06的同弦冲突、跨度、换把和高品位限制，也不评价听感或是否愿意练习。不把调式内音作为强制条件，允许音乐内容中的变化音。

## 亲自验证

双击根目录 `检查音乐规则.command`，先看到默认样例“音乐基础检查通过”、6秒，然后看到120 BPM、8拍、4秒；窗口等待回车关闭。当前网页仍为占位页面，没有加入业务按钮。

在项目根目录也可逐项运行：

```bash
backend/.venv/bin/python backend/scripts/check_music.py
backend/.venv/bin/python backend/scripts/check_music.py --case four-seconds
backend/.venv/bin/python backend/scripts/check_music.py --case too-long
backend/.venv/bin/python backend/scripts/check_music.py --case wrong-pitch
backend/.venv/bin/python backend/scripts/check_music.py --case local-tempo
backend/.venv/bin/python backend/scripts/check_music.py --case local-key
backend/.venv/bin/python backend/scripts/check_music.py --case percussion
```

前两条成功返回0；其余故意制造错误，显示“音乐基础检查失败”并返回1。错误包含 `measures...events...` 或作品级规则；内存修改不会写回原样例。

检查某个已保存的候选：在上述命令后添加 `--file "runtime/ai/请求编号/candidate.json"`；支持任务04包含composition的候选，也支持直接作品JSON。模型返回了正确JSON仍可能有音乐错误，检查失败就不能进入成品交付。

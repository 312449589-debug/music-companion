## 用户确认的首版规则（2026-10-10）

- 标准定弦，优先空弦和前五品，最高第7品。
- 第6—7品音符不超过全曲音符的10%。按有音高事件数计数，休止不计；连音片段保留在主数据中，各片段分别计数。不向上取整：12个音符最多1个高品位音符，9个音符不允许高品位音符。
- 同时按住的最高与最低品位之差不超过3，空弦不参与按弦跨度。例如第2与第5品可通过，第3与第7品被拒绝。
- 相邻指型最低按弦品位的移动不超过3品。按音符开始/结束时刻扫描仍在发声的音符；全空弦或休止期间不建立新的按弦位置，之后仍与上一次按弦位置比较。
- 同一根弦不能承载重叠发声的两个事件。相邻延音片段在同一个时刻交接，不算重叠；重新分配后仍使用同一根弦。
- 难度主要参考作品BPM，返回原始BPM，不生成难度等级，不用音符密度替代BPM。

这些是本产品首版限制，不是演奏难度的通用定律。跨度、换把和同弦检查不能判断每个人是否按得舒服，也不能保证四指安排、横按或旋律听感合格，仍需人工审阅。

## 分配器做什么

固定音高、时间、旋律/伴奏身份、节奏、BPM和调性，只为音符重新选择符合标准定弦的弦号与品位。优先选择更少高品位和较低品位的候选，结合仍在发声的音符检查冲突。休止及源对象不改动。

搜索最多保留32组候选、最多探索50000次，控制本机计算量；这些是实现开销限制。搜索失败明确报错，不改音高、不偷偷放宽音乐规则，也不代表人类一定找不到其他可弹指法。最终分配结果重新执行基础音乐规则和指型规则；有任何错误就不交付。

## 自己操作验证

双击根目录 `检查指型.command`：应看到“自动指型规则通过”，80 BPM、12个音符、0个高品位音符、最大按弦品位差1、最大位置移动2，并逐个列出音符的弦号、品位、音高和时值。此入口不请求AI、不生成音频、不修改文件。

在项目根目录运行：

```bash
backend/.venv/bin/python backend/scripts/check_fingering.py --assign
backend/.venv/bin/python backend/scripts/check_fingering.py --case same-string
backend/.venv/bin/python backend/scripts/check_fingering.py --case same-string --assign
backend/.venv/bin/python backend/scripts/check_fingering.py --case wide-span
```

依次预期：重新分配样例后通过；同弦冲突被拒绝；保持音高重新分配到其他弦后通过；第3—7品跨度被拒绝。故意失败的命令返回1。查看某个真实候选可添加 `--file "runtime/ai/请求编号/candidate.json"`。

## 供人工审阅的固定两小节样例

标准定弦、4/4拍、80 BPM。每个小节4拍，旋律每拍一个四分音符，低音各持续两拍。这里“空弦”是第0品。

第一小节（C）：

- 第1拍：五弦3品低音，与一弦空弦旋律同时弹；低音持续至第3拍。
- 第2拍：一弦3品旋律。
- 第3拍：四弦2品低音，与二弦1品旋律同时弹；低音持续至小节结束。
- 第4拍：一弦空弦旋律。

第二小节（Am）：

- 第1拍：五弦空弦低音，与二弦1品旋律同时弹；低音持续至第3拍。
- 第2拍：一弦空弦旋律。
- 第3拍：四弦2品低音，与一弦空弦旋律同时弹；低音持续至小节结束。
- 第4拍：二弦1品旋律。

这份样例明确是固定诊断数据，不冒充AI作品；分配器处理后弦位相同。请懂指弹的人核对是否有明显按弦、持音、换把问题，留下具体意见；仅“代码检查通过”不算人工意见。谱面和音频属于后续任务07/09，目前只有上述文字和诊断事件列表。

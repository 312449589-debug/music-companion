## 改动文件与作用

- `backend/app/jobs.py`：一个后台工作线程，最多接收4个尚未完成任务（含运行中），超出返回429。将任务状态写入各自清单；启动时把之前queued/running记录标为重启中断，不自动重新付费生成。相同目录只能有一个服务，避免另一个服务误处理仍在运行的任务。
- `backend/app/api.py`：提交文字、查询状态、获取音频与PDF。输入只允许1—1000字符的非空文字。作品ready前文件接口返回409；ready后只允许清单中已验证的固定文件，校验路径、大小和SHA256。不向客户端暴露内部路径、模型原始错误或密钥。
- `backend/app/main.py`：启动/停止任务服务，注册API与错误处理，开发代理允许POST；`MUSIC_PRINT_BASE_URL`指定本机打印入口，`MUSIC_JOBS_ROOT`用于独立诊断目录，正常启动无需改配置。
- `backend/app/music/pipeline.py`：支持执行已排队的同一个任务编号，拒绝覆盖现成或失败作品；音乐生成和导出规则沿用任务11。
- `backend/tests/test_jobs_api.py`、`test_pipeline.py`：验证状态、队列上限、不阻塞健康请求、失败、重启、独立目录、文件篡改拒绝、类型与Range请求；隔离测试中的替身不作为真实作曲成功证据。
- `backend/scripts/check_jobs_api.py`、`检查异步接口.command`：通过真实HTTP提交并查询两个真实AI任务，分别检查文件下载和播放分段。双击入口自动启用8001独立诊断服务，结果存到诊断目录；退出只停止自己启动的子进程，不操作主服务。

## 接口手动核对

在主服务运行时，Chrome打开 `http://127.0.0.1:8000/docs`，展开POST `/api/generate`，点击Try it out，输入 `{"prompt":"温暖安静，适合夜晚弹奏"}`，点击Execute：响应202并返回job_id。GET `/api/jobs/{job_id}`用该编号反复查询，应看到queued/running/ready或明确failed；ready返回共同作品编号、主数据、alphaTex、音频时长与文件URL。

GET `/api/jobs/{job_id}/audio` 默认inline试听；加 `?download=true` 下载同一MP3。GET `/api/jobs/{job_id}/pdf` 默认下载，加 `?download=false` 可在Chrome直接查看。Content-Type分别audio/mpeg、application/pdf；文件名带任务编号。音频支持Chrome的Range206请求。

无效编号404，空白/错误类型/额外字段输入422，队列满429，未ready或缺失/内容改变的文件409。重新获取文件不会调用模型。

仅检查已有主服务成品（不调用模型）：

```sh
backend/.venv/bin/python backend/scripts/check_jobs_api.py --existing '<实际任务编号>'
```

# 任务13：首页布局和提示词输入

本任务只完成首页及输入交互，尚未接入网页提交生成。后端真实生成接口已在任务12完成，网页联动属于任务14。

## 如何验证

1. 在Chrome打开 http://127.0.0.1:8000/ 。如果服务未启动，先双击项目根目录的“启动音乐伙伴.command”，打开它提供的网页入口。
2. 应看到品牌、左侧描述框与三个示例、右侧空作品区，以及下方试听区和MP3/PDF独立下载区。作品区显示“还没有作品”，没有预填乐谱或音频。
3. 依次点击“温暖安静”“轻快明亮”“略带忧伤”，描述框应换成相应文字。可以直接编辑文字；示例不触发生成，也不收取模型费用。
4. 清空描述或只输入空格，“生成指弹作品”按钮应禁用，并显示“请先输入描述，或选择一个示例。”
5. 有内容时点击生成按钮，目前只显示“描述已保留，生成入口暂未开放。”文字保留，作品区仍为空。此步骤不调用后端，不作为AI功能验收。
6. 试听、下载MP3、下载PDF均为禁用状态。滚动到页尾可完整看到两个下载入口。
7. 将Chrome缩放调到125%，应仍能滚动查看全部区域；较窄宽度下下载入口上下排列，更窄时页面改成单列。验证后恢复100%。
